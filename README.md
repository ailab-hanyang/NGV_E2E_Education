# NGV_E2E_Education

## Getting started
### 1. Install CARLA and Start the CARLA Simulator (0.9.15)
* for Ubuntu 20.04 
```bash
cd ~/(your path to CARLA)
./CarlaUE4.sh
```

### 2. Install python tools
* for Ubuntu 20.04 
```bash
sudo apt install python3-pip
pip install pygame numpy
```

### 3. Start the code
* for Ubuntu 20.04
```bash
python3 (code you want to use).py
```
